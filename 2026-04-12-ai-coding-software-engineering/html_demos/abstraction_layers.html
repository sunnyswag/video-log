The Code Axis.
I · LANGUAGE
N.01 Machine Instructions汇编 · ASM 直接操作寄存器 ▸
Hides ⟶ Nothing

最底层。每个寄存器、每个内存偏移、每个中断向量都要手动管理。换一个 CPU 架构，代码就完全作废。

MOV  AX, [0x1234]
ADD  AX, BX
INT  0x21
; 每一行对应一条 CPU 指令
N.02 The C LanguageC · 编译器 隐藏指令集差异 ▸
Hides ⟶ CPU specifics

不再关心具体的 CPU 型号、寄存器和指令集——编译器替你做指令选择和寄存器分配。但内存仍需手动 malloc / free。

int result = a + b;
char *buf = malloc(256);
// 编译器处理指令选择
// 但内存仍需手动管理
N.03 Object-OrientedOOP · 面向对象 封装数据与行为 ▸
Hides ⟶ Global state

数据和操作绑定在一起，通过继承和多态复用逻辑。不用在全局追踪"哪个函数操作哪块数据"——对象自己管理自己的状态。

class TextFile {
  save() { /* 自己管理自己 */ }
  render() { ... }
}
// 数据 + 行为封装在一起
N.04 Libraries & Packages生态 · 复用 复用别人的方案 ▸
Hides ⟶ Solved problems

npm / pip / cargo——把别人解决过的问题打包复用。不用自己实现 HTTP 客户端、JSON 解析、加密算法。但每种语言一套生态，跨语言的重复劳动仍然存在。

import requests  # Python
const axios = require('axios') // JS

// 同一个问题，每种语言各写一套
// 跨语言的重复仍然存在
The Platform Axis.
II · ENVIRONMENT
N.05 The Operating SystemOS · 内核 隐藏硬件调度 ▸
Hides ⟶ Hardware scheduling

进程调度、内存分页、文件系统、设备驱动、权限隔离。应用程序不再需要知道磁盘怎么转、内存怎么分页、多个程序怎么共享 CPU。

File f = open("data.txt");
read(f, buf, 256);
// 不知道磁盘怎么转
// 不知道内存怎么分页
N.06 Browser & the Web跨平台 · Web 隐藏平台差异 ▸
Hides ⟶ Platform differences

同一份代码在 Windows、macOS、Linux、手机上都能运行。浏览器处理渲染引擎差异、网络协议栈、安全沙箱、GPU 加速。

<button onclick="alert('hi')">
  Click me
</button>
<!-- 在任何设备上都能运行 -->
N.07 Cloud & Serverless云 · 基础设施 隐藏运维与资源 ▸
Hides ⟶ Infrastructure

不用关心服务器在哪、怎么扩缩容、如何做负载均衡。上传一个函数就能运行。从"我部署软件"到"我使用服务"的跃迁。

// Serverless function
export default async (req) => {
  return Response("Hello");
}
// 不知道跑在哪台机器上
