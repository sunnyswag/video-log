# B 站通用投稿工具

## 一分钟用法

1. 剪好视频，在 **D:\video-log**（git 仓库）里新建一个英文命名的项目文件夹，例如 `D:\video-log\2026-12-31-my-topic\`；
2. 把视频、投稿信息文件放进文件夹，**统一命名**（文件名主体一致）：

   ```
   D:\video-log\2026-12-31-my-topic\
   ├── my-topic.mp4    ← 视频（必需，体积大，已被 .gitignore 忽略不会提交）
   ├── my-topic.json   ← 投稿信息（必需，从「视频信息模板.json」复制改名）
   ├── my-topic.srt    ← 字幕（可选，会提交到仓库；B 站接口不支持字幕，传完视频去创作中心手动传）
   └── my-topic.jpg    ← 封面（可选；也可在 json 的 cover 里指定别的图片文件名）
   ```

3. 在本工具目录先运行 `powershell -File .\upload.ps1 -Check`，检查所有投稿项目的本地文件和投稿信息；
4. 双击 `上传视频.bat`，用 **↑↓ 方向键**选择要上传的项目（默认停在最近修改的那个），
   **Enter** 确认 → 核对投稿摘要 → 输入 **YES** 开始上传。随后到 B 站创作中心手动上传字幕并确认稿件状态。

## json 字段说明

| 字段 | 必填 | 说明 |
|---|---|---|
| title | 是 | 视频标题（80 字以内） |
| tid | 是 | 投稿分区编号，231 = 科技→计算机技术；其他分区编号可在 B 站投稿页 URL 里看到 |
| tag | 是 | 标签，英文逗号分隔，最多 10 个 |
| desc | 否 | 视频简介，可多行 |
| cover | 否 | 项目外层的封面文件名；显式填写后文件必须存在。不填时依次找：`<统一名称>.jpg` → `<统一名称>.png` → `封面.jpg`，都没有就不设封面 |
| copyright | 否 | 1 = 自制（默认），2 = 转载；转载时建议同时填 `source` 字段写来源 |
| videos | 否 | 多 P 投稿列出项目外层的各视频文件名，如 `["a.mp4", "b.mp4"]`，无须另备同名 MP4；留空 `[]` 则使用 `<统一名称>.mp4` |

## 这个工具文件夹里都有什么

| 文件 | 作用 |
|---|---|
| 上传视频.bat | 双击入口 |
| upload.ps1 | 主脚本（扫描、预检、选择、确认、调用上传） |
| biliup.exe | biliup 命令行上传工具 v1.2.11，全机只此一份 |
| cookies.json | B 站登录凭据（每次上传前自动刷新；**不要发给别人**） |
| 视频信息模板.json | 新项目复制用 |

## 维护

- 登录失效时：在本文件夹打开终端，运行 `.\biliup.exe login`，用 B 站 App 扫码；
- 列出项目：运行 `powershell -File .\upload.ps1 -List`；只读预检：运行 `powershell -File .\upload.ps1 -Check`（检查失败返回非零退出码）；两者都不需要登录凭据；
- 验证别处的项目目录：增加 `-Root '目标目录'`；默认从本工具目录定位 `D:\video-log`；
- 换电脑：整个 `D:\video-log\tools\biliup-upload` 文件夹拷过去即可用；视频项目在 `D:\video-log`（git 仓库，clone 后把被忽略的大文件单独拷回）。

## 常见问题

- **某个文件夹没被扫到**：确认项目位于 `D:\video-log` 的直接子目录，且外层有投稿 `.json`；单 P 默认使用同名 MP4，多 P 在 `videos` 数组列出全部文件名；
- **字幕**：本工具不会自动上传 `.srt`；投稿完成后到创作中心手动上传，并确认稿件状态；
- **投稿频繁被拒（错误码 601）**：B 站限流，过段时间再传。
